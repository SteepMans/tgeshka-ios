# TGeshka для iOS: что нового

`CHANGELOG-tgeshka.json` в корне — список изменений TGeshka (не Telegram). Он вшивается в приложение ресурсом
(`Telegram/BUILD`) и показывается в «Настройки → TGeshka → Что нового» и один раз после обновления. Формат: массив
`{"version", "date", "items"}`, новые версии сверху, `items` — строки на русском. Версия — как в теге `vX.Y.Z`.

- PR с заметным для пользователя изменением дописывает пункт в верхнюю версию; если она уже вышла тегом, заводит
  новую со следующей версией.
- Пишется словами пользователя, что он видит: без имён типов и деталей сборки, 3–7 коротких пунктов на версию.
  Изменения только CI и сборки в список не идут.
- Слияние нового релиза Telegram-iOS — одной строкой «Обновлено до Telegram X.Y», напоминание есть в PR
  от `upstream-sync.yml`.
